# zed-harnlang

Native Zed extension for Harn language (`.harn`).

- Extension ID: `harnlang`
- Package: `zed-harnlang`
- Language: `Harn`
- LSP: `harn-lsp`

## Build

```bash
rustup target add wasm32-wasip2
```

## Load in Zed
0. install harn itself - https://harnlang.com/getting-started.html#install-harn
1. Open Zed
2. Command palette → `zed: extensions`
3. Search for `Harn`, click **install**
